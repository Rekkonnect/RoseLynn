# [RoseLynn.Writing](https://www.nuget.org/packages/RoseLynn.Writing/)

`RoseLynn.Writing` contains code-writing and source-building helpers used by the generator and testing packages. It provides indented string builders, C# code writers, source-file builders, and related tokenization utilities.

Reference it directly when building a source generator that needs structured output helpers, or use [RoseLynn.Generators](../RoseLynn.Generators/index.md), which depends on it.
