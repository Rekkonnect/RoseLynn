# [RoseLynn.Bundle.Analysis](https://www.nuget.org/packages/RoseLynn.Bundle.Analysis/)

`RoseLynn.Bundle.Analysis` is a convenience bundle package. It has no API of its own; it references [RoseLynn.Analyzers](../RoseLynn.Analyzers/index.md), [RoseLynn.CodeFixes](../RoseLynn.CodeFixes/index.md), and [RoseLynn.Generators](../RoseLynn.Generators/index.md).

Use it when a project wants the full analyzer, code-fix, and generator surface without adding the three package references individually.
